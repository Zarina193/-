# Дәрігерге жазылу жүйесі

## 1. Жоба туралы

«Дәрігерге жазылу жүйесі» — пациенттерге дәрігерлер туралы ақпаратты көруге, қажетті маманды таңдауға және қабылдауға жазылуға мүмкіндік беретін веб-жүйе.

## 2. Жобаның мақсаты

Дәрігер қабылдауына жазылу үдерісін жеңілдету және медициналық ақпаратты бір жүйеде ұйымдастыру.

## 3. Жобаның міндеттері

- Пайдаланушыларды тіркеу және жүйеге кіру.
- Дәрігерлер туралы ақпаратты көрсету.
- Дәрігерлердің мамандықтарын көрсету.
- Қабылдау күні мен уақытын таңдау.
- Қабылдауға жазылу күйін бақылау.
- Медициналық анализдер мен олардың нәтижелерін сақтау.
- Қажетті дәрігерді іздеу.

## 4. Жүйенің мүмкіндіктері

- Пайдаланушыны тіркеу және авторизациялау.
- Дәрігерлер тізімін қарау.
- Дәрігерді мамандығы бойынша іздеу.
- Қабылдау уақытына жазылу.
- Анализ нәтижелерін тіркеу және қарау.

## 5. Қолданылатын технологиялар

- HTML5 — веб-беттердің құрылымы.
- CSS3 — сайт дизайны және адаптивті интерфейс.
- JavaScript — интерактивті функциялар.
- MySQL — деректер базасы.
- Git және GitHub — жобаны сақтау және басқару.

## 6. Сайттың негізгі беттері

1. `index.html` — басты бет.
2. `login.html` — тіркелу және кіру беті.
3. `doctors.html` — дәрігерлер тізімі және қабылдауға жазылу беті.

## 7. Деректер базасының кестелері

- `Users` — пайдаланушылар туралы ақпарат.
- `Specialists` — дәрігерлердің мамандықтары.
- `Doctors` — дәрігерлер туралы ақпарат.
- `Appointments` — қабылдауға жазылу.
- `Medical_Analyses` — медициналық анализдер.
- `Analysis_Results` — анализ нәтижелері.

## 8. Жобаны іске қосу

1. Жоба файлдарын компьютерге жүктеп алу.
2. Жоба бумасын ашу.
3. `index.html` файлын браузер арқылы іске қосу.
4. Сайт беттерінің жұмысын тексеру.

## 9. Күтілетін нәтиже

Дәрігерлер туралы ақпаратты көрсетуге және пациенттердің қабылдауға жазылуын ұйымдастыруға арналған ыңғайлы веб-жүйенің бастапқы нұсқасын әзірлеу.
