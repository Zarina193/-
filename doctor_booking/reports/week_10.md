# 10-апта есебі — Дәрігерге жазылу жүйесі

**Студент:** Минаварова Зарина, АЖ-335

**Мақсаты:** статикалық интерфейсті PHP файлдарына көшіру және формаларды серверде өңдеу.

**Орындалған жұмыс:** `index.php`, `register.php`, `login.php`, `appointments.php` және қабылдау формалары құрылды. Ортақ навигация мен төменгі бөлік `includes/header.php`, `includes/footer.php` арқылы бөлінді. Формалар `$_POST` арқылы қабылданады, `$_GET` арқылы жазылу ID және нәтиже статусы оқылады. Енгізілген мәліметтер серверде тексеріледі.

**Нәтиже:** PHP беттері мен өңделетін формалар дайын.

**Прогресс (үлгілік бағалау):** 50%.

**Кездесуі мүмкін мәселе:** PHP файлдары браузерде ашылғанда код орындалмайды. **Шешім:** XAMPP Apache арқылы `localhost` адресін қолдану.

**Келесі апта:** PDO арқылы MySQL-ға қосылу және аутентификация.

**GitHub коммиттер:** нақты коммит сілтемелерін жүктегеннен кейін енгізіңіз. Ұсынылатын хабарламалар: `Create PHP page structure`, `Extract shared header and footer`, `Add server-side form validation`.
