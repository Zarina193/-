# Дәрігерге жазылу жүйесі (MedBooking)

**Тақырып:** Дәрігерге жазылу жүйесі  
**Технологиялар:** PHP 8+, MySQL 8+, PDO, HTML, CSS, JavaScript  
**Орындаған:** Минаварова Зарина, АЖ-335  
**Қамтылған апталар:** 10, 11, 12

## Мақсаты
Пациенттердің дәрігерге онлайн жазылуын ұйымдастыру және өз жазылуларын басқару.

## Жоба мүмкіндіктері
- Басты бет және адаптивті интерфейс.
- Тіркелу, кіру, шығу; парольдер `password_hash()` арқылы сақталады.
- Жеке кабинеттегі қабылдаулар тізімі.
- Қабылдауды қосу, қарау, өзгерту және жою (CRUD).
- Серверлік валидация, PDO prepared statements, XSS-ке қарсы escaping, CSRF токені.
- Бір дәрігерге бір күн/уақытқа екі адам жазыла алмайды (UNIQUE шектеуі).

## Жергілікті іске қосу (XAMPP)
1. XAMPP-та **Apache** және **MySQL** қызметтерін қосыңыз.
2. `doctor_booking` қалтасын `C:\xampp\htdocs\` ішіне көшіріңіз.
3. `http://localhost/phpmyadmin` ашып, **Import** арқылы `sql/database.sql` файлын импорттаңыз.
4. `includes/config.php` файлына MySQL логин/паролін жазыңыз (XAMPP-та көбіне `root` және бос пароль).
5. Браузерден `http://localhost/doctor_booking/` ашыңыз.
6. Тіркеліңіз, жүйеге кіріңіз, қабылдау қосыңыз, өзгертіңіз және жойыңыз.

> Дерекқорды импорттамай тіркелу/жазылу жұмыс істемейді. Нақты серверде қате туралы толық мәліметті пайдаланушыға көрсетпеңіз және HTTPS қолданыңыз. Бұл — оқу жобасы, нақты пациент деректерін енгізбеңіз.

## Құрылымы
- `index.php` — басты бет
- `register.php`, `login.php`, `logout.php` — аутентификация
- `appointments.php` — Read (тізім)
- `appointment_create.php` — Create
- `appointment_edit.php` — Update
- `appointment_delete.php` — Delete (POST)
- `includes/` — config, PDO, функциялар, ортақ header/footer және форма
- `assets/style.css` — адаптивті стиль
- `sql/database.sql` — users, doctors, appointments кестелері
- `reports/` — 10–12 апта есептері және тексеру тізімі

## Тестілеу
`reports/TEST_CHECKLIST.md` файлындағы сценарийлерді XAMPP-та тексеріңіз. Жоба кодына PHP синтаксистік тексеріс жасалды; MySQL-пен толық интеграциялық тест жергілікті ортада орындалуы тиіс.

## GitHub
Жоба қалтасын өз репозиторийіңізге жүктеңіз. Әр аптаға кемінде **3 мағыналы коммит** талап етіледі. `reports/` ішіндегі коммит үлгілерін нақты жасағаннан кейін ғана есепке енгізіңіз.
